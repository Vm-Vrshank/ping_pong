# 🟢 PONG

A retro-styled, neon terminal Pong game built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

## 🎮 Features

- Neon green CRT-style aesthetic with scanline overlay
- Smooth mouse and keyboard controls for the player paddle
- CPU opponent with reactive AI
- Ball speed increases with each paddle hit
- Angle deflection based on where the ball hits the paddle
- Particle effects on collisions and scoring
- Glowing ball trail
- Scoreboard — first to 7 wins

## 🕹️ Controls

| Input | Action |
|-------|--------|
| Mouse (over canvas) | Move paddle |
| ↑ / W | Move paddle up |
| ↓ / S | Move paddle down |

## 🚀 Getting Started

No installation needed. Just open the file in your browser:

1. Clone the repo or download `pong.html`
2. Open `pong.html` in any modern browser
3. Click **START GAME** and play!

## 🛠️ Built With

- HTML5 Canvas
- CSS3 (custom properties, animations)
- Vanilla JavaScript (requestAnimationFrame game loop)
